# Loans and renewals

## Checkout terms and active-loan limits
- A member may have five active loans. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- An available ordinary book is loaned for 21 calendar days, due at branch closing on the due date. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- At branch closure, existing due dates use that branch's published calendar, not the device timezone. [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]
- Reference books remain on site. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- Offline checkout is not supported: show the unavailable-service message and create no loan. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- Locker reservation is not checkout; the active loan begins only after verified pickup. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- A member at the five-loan limit cannot use locker pickup to evade the limit. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- Branch transfers preserve the hold queue sequence and active-loan count. [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]
- An item reported lost retains its loan until staff confirms replacement or recovery; a locker code cannot clear that debt. [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]

## Renewals
- Renewal is available twice, each extending the existing due date by 14 days, but not when another member has an active hold. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- Automatic third renewals are DEFERRED and NOT APPROVED for release 6; the two-renewal limit is kept. The decision states it is not an implementation request and defers demand investigation to the next quarter. [3b39abb6-997d-48d8-a11e-da7b2bf6e923]
- The same deferred proposal also covered transferable family pickup codes and allowing suspended members to collect already-assigned locker holds; that exception was explicitly not approved. [3b39abb6-997d-48d8-a11e-da7b2bf6e923]

## Suspension effects on loans
- Membership suspension blocks new checkout, renewal, locker assignment and locker pickup; it never blocks returning a borrowed item. [922e733e-29b5-4bcd-b8db-38d8acd6b2d2]
- A return may be recorded for a suspended member and must reduce the active-loan count exactly once. [cd729138-dd10-4c76-b209-d2b44a4d104b]

## Identity, idempotency and operation records
- Replaying a successful checkout or return operation returns its prior receipt and does not alter counts again. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- A lost network acknowledgement must not create a second loan. [922e733e-29b5-4bcd-b8db-38d8acd6b2d2]
- Every circulation or locker action records membership ID, item ID, branch, actor and outcome under one operation ID. [922e733e-29b5-4bcd-b8db-38d8acd6b2d2]
- Only a desk librarian may resolve an identity mismatch; an unattended terminal must leave custody unchanged. [922e733e-29b5-4bcd-b8db-38d8acd6b2d2]
- The service charter's identity, suspension and idempotency requirements apply to all exception paths. [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]

## Observable expectations
- With five active loans, a further checkout must not create a sixth loan, including through locker pickup. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- An offline checkout attempt must show the unavailable-service message and create no loan. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- A return recorded for a suspended member must be accepted and reduce the active-loan count exactly once. [cd729138-dd10-4c76-b209-d2b44a4d104b] [922e733e-29b5-4bcd-b8db-38d8acd6b2d2]
- Renewal must be available twice and each must extend the existing due date by 14 days; it must not be available when another member has an active hold. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- Replaying a successful checkout or return must return its prior receipt and must not alter counts again. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- A lost network acknowledgement must not create a second loan. [922e733e-29b5-4bcd-b8db-38d8acd6b2d2]
- Locker reservation alone must not start an active loan; the active loan begins only after verified pickup. [cd729138-dd10-4c76-b209-d2b44a4d104b]
- An item reported lost retains its loan until staff confirms replacement or recovery; a locker code cannot clear that debt. [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]
- Replay of checkout or return must not alter active-loan counts again. [cd729138-dd10-4c76-b209-d2b44a4d104b]
