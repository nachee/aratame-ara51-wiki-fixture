# Exception handling and audit

## Scope and authority

The release 6 daily exception handbook was approved by Ivo Reed under Mara Bell's release delegation on 2026-08-07 [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]. The Juniper service charter was approved by library director Mara Bell on 2026-08-03 for release 6 [922e733e-29b5-4bcd-b8db-38d8acd6b2d2]. The service charter's identity, suspension and idempotency requirements apply to all exception paths [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]. These rules apply at desks and lockers [922e733e-29b5-4bcd-b8db-38d8acd6b2d2]. The charter documents product authority only; it grants no permission to publish data or execute tests in any other system [922e733e-29b5-4bcd-b8db-38d8acd6b2d2].

QA:
- Exception paths must satisfy the service charter's identity, suspension and idempotency requirements [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04].

## Return and hold exceptions

Damaged returns enter inspection and do not satisfy the next hold until a librarian clears them [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]. An item reported lost retains its loan until staff confirms replacement or recovery; a locker code cannot clear that debt [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]. Branch transfers preserve the hold queue sequence and active-loan count [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]. A member may cancel an unassigned hold online [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]. Cancelling an assigned but uncollected hold requires the locker service to revoke its code; if revocation cannot be confirmed the item remains reserved for staff review [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04].

QA:
- Damaged returns must not satisfy the next hold until a librarian clears them [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04].
- A lost item's loan remains until staff confirms replacement or recovery; a locker code cannot clear that debt [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04].
- Cancelling an assigned but uncollected hold requires locker-code revocation; if revocation cannot be confirmed, the item remains reserved for staff review [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04].

## Locker reconciliation and network exceptions

Daily reconciliation compares physical locker occupancy with pending assignments and sends discrepancies to staff, without fabricating a pickup or a return [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04]. A lost network acknowledgement must not create a second loan or release a second compartment [922e733e-29b5-4bcd-b8db-38d8acd6b2d2].

QA:
- Daily reconciliation must not fabricate a pickup or a return [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04].
- A lost network acknowledgement must not create a second loan or release a second compartment [922e733e-29b5-4bcd-b8db-38d8acd6b2d2].

## Suspension, identity and custody exceptions

Membership suspension blocks new checkout, renewal, locker assignment and locker pickup; it never blocks returning a borrowed item [922e733e-29b5-4bcd-b8db-38d8acd6b2d2]. Only a desk librarian may resolve an identity mismatch; an unattended terminal must leave custody unchanged [922e733e-29b5-4bcd-b8db-38d8acd6b2d2].

QA:
- Suspension must not block returning a borrowed item [922e733e-29b5-4bcd-b8db-38d8acd6b2d2].
- An unattended terminal must leave custody unchanged on identity mismatch [922e733e-29b5-4bcd-b8db-38d8acd6b2d2].

## Audit records and retention

Every circulation or locker action records membership ID, item ID, branch, actor and outcome under one operation ID [922e733e-29b5-4bcd-b8db-38d8acd6b2d2]. Audit retention is 90 days [922e733e-29b5-4bcd-b8db-38d8acd6b2d2].

## Operation receipts and batch failures

A desk receipt lists each operation separately; batch return failure must not erase successful earlier returns [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04].

QA:
- A batch return failure must not erase successful earlier returns [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04].

## Branch closure and due dates

At branch closure, existing due dates use that branch's published calendar, not the device timezone [113cdf43-46ec-4e9b-ab84-bdb1da0ddb04].
